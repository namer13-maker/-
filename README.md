# בית המדרש הדיגיטלי — הוראות העלאה ל-GitHub Pages

אתר סטטי לחלוטין: עיון בכל הש"ס + תרגול סוגיות מנותחות. ללא צורך בשרת או ב-AI.

## מה יש בחבילה

```
index.html              ← האפליקציה (קובץ אחד, נטען בדפדפן)
index.json              ← רשימת כל המסכתות
data/                   ← 37 קבצי מסכתות (מנוקד + לא מנוקד)
analyzed/
  index.json            ← רשימת הסוגיות המנותחות
  Sukkah_2a.json        ← סוכה ב ע"א, מחולקת לנושאים ומתויגת
```

## העלאה ל-GitHub Pages — צעד אחר צעד

1. היכנס ל-github.com והתחבר לחשבונך.
2. לחץ על הכפתור הירוק **New** ליצירת מאגר (repository) חדש.
   - תן שם, למשל `gemara`.
   - סמן **Public**.
   - לחץ **Create repository**.
3. במסך החדש לחץ על הקישור **uploading an existing file**.
4. **גרור את כל תוכן החבילה הזו** (הקובץ index.html, התיקייה data, התיקייה analyzed, וקובץ index.json) לאזור ההעלאה.
   - חשוב: גרור את הקבצים והתיקיות עצמם — כך שה-index.html יהיה ב**שורש** המאגר, לא בתוך תת-תיקייה.
5. לחץ **Commit changes** והמתן שההעלאה תסתיים.
6. עבור ל-**Settings** (בתפריט העליון של המאגר) → בתפריט הצדדי **Pages**.
7. תחת **Branch** בחר `main` ותיקייה `/ (root)`, ולחץ **Save**.
8. המתן 1-2 דקות. רענן את הדף — תופיע כתובת כמו:
   `https://<שם-המשתמש-שלך>.github.io/gemara/`
9. זו כתובת האתר שלך. שתף אותה עם תלמידים.

## עדכון האתר בעתיד

כדי להוסיף סוגיות מנותחות חדשות:
1. הוסף קובץ JSON חדש בתיקיית `analyzed/` (בפורמט של Sukkah_2a.json).
2. הוסף שורה עבורו ב-`analyzed/index.json`.
3. העלה את הקבצים המעודכנים למאגר (Add file → Upload files).
האתר יתעדכן אוטומטית.

## הערות

- אם האתר מציג "שגיאה בטעינת המאגר", בדוק שכל הקבצים והתיקיות הועלו וש-index.html בשורש.
- האתר עובד בכל דפדפן מודרני, כולל נייד.
